# Student Performance Analytics and AI-Based Prediction

A Data Analytics and Machine Learning project developed by Devank Mudgal.

## Project Overview
This project analyses student performance indicators and demonstrates how machine learning can estimate final scores using sample data.

## Objectives
- Analyse student performance data.
- Explore study hours, attendance, assignments, quizzes and sleep hours.
- Visualise data using charts.
- Build a Random Forest regression model.
- Evaluate predictions using MAE and R-squared.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Machine Learning

## Dataset
The project includes a synthetic dataset containing 40 sample records. It is for educational demonstration only and does not represent real students.

## Project Files
- student_performance_ai_project.py — Python source code
- student_performance_sample_dataset.csv — Sample dataset
- Student_Performance_Analytics_AI_Project_Report.pdf — Project report
- requirements.txt — Python dependencies

## Installation
Install the required libraries:

pip install -r requirements.txt

## How to Run
Keep the Python file and CSV dataset in the same folder, then run:

python student_performance_ai_project.py

## Output
The script generates data visualisations, model evaluation metrics and test predictions.

## Limitations
The dataset is small and synthetic. Model predictions are for demonstration only and are not validated for real-world academic decisions.
